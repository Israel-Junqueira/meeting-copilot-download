# Meeting Copilot

Copiloto de reunião para Windows: transcreve a conversa **ao vivo** e sugere **o que dizer a seguir** em tempo real, com base no seu próprio contexto.

## ⬇️ Download

**[Baixar a versão mais recente (Windows)](https://github.com/Israel-Junqueira/meeting-copilot-download/releases/latest)**

Na página que abrir, clique em `MeetingCopilot-Setup-x.x.x.exe`.

## Como instalar

1. Execute o instalador baixado.
2. Se o Windows mostrar "O Windows protegeu seu PC", clique em **Mais informações → Executar assim mesmo** (o app ainda não tem assinatura digital).
3. Abra o **Meeting Copilot**, clique na engrenagem ⚙ e cole sua **chave da OpenAI** ([crie a sua aqui](https://platform.openai.com/api-keys)).
4. Anexe seu contexto (.md), salve e clique em **Iniciar Sessão**.
